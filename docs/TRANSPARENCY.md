# Transparency

This page labels what the modules in this tree do. It is not a measurement of a live vendor call. Where a module cannot see an outcome, the row says so. Unknown is not a pass.

Recursion telemetry is `none` on every row. No module listed here starts a telemetry client. When an engine child can speak to its vendor, that traffic is named under "What leaves the machine". This page does not call that traffic Recursion telemetry, and it does not claim the child's own reporting is off unless the cited module sets that switch.

The product contract says a route is not made stricter than the engine's own program by default, and that containment is configured by the user or by a plugin. This tree does not apply a container or a network policy. `core/recursion_core/daemon/launcher.py` has no containment call, and no containment probe is in this tree. This page therefore does not say that any route is contained. Where the code refuses a launch, the row names that refusal.

A cited module path is a backtick path that contains a slash and ends in the .py suffix. `tools/test_transparency.py` fails when that file is not in the tree, when a row below is missing, when a telemetry cell is not `none`, and when `README.md`, `SECURITY.md` (if that file exists), or anything under `docs/` carries a refused claim. The refused spellings are in the test, not repeated here, because this page is one of the files the check reads.
