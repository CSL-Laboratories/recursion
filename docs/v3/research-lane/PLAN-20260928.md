# Recursion v3 research-lane plan (2026-09-28)

The packet list synthesized from the Astra report, the Mark 3 Gemini harness conversation, and
the Owner's 2026-09-28 answers (Owner answers take precedence). Each row becomes a Research
Packet per [RESEARCH-PROCEDURE](../RESEARCH-PROCEDURE.md). Priority is the ordering to open them.

## Owner-priority lanes (P0 — spec identity and architecture)

| Lane | Question | Method | Gate | Evidence target |
|---|---|---|---|---|
| `stream-ownership` | Can Recursion own the canonical prompt + model token stream and multiplex it to N views without an extra model call? | design + fixture; replay a captured token stream through the canonical broker | new `experiments/v3/stream-ownership/check.py` (provider-free) | locally-observed |
| `recursion-session` | Does a canonical Session spanning route epochs preserve directive/decision/checkpoint continuity across an engine switch? | fault fixture: native→upstream and upstream→upstream mid-session | new session-continuity fixture | locally-observed |
| `prompt-equivalence` | Does the same GoalSpec revision + capsule digest compile to an equivalent control prefix on every engine? | content-addressed compiled-prompt manifest + compile receipts; diff across adapters | new `check.py` comparing manifests | locally-observed |
| `model-plane` | Are local / BYOK / subscription / upstream-harness unified as one route suite with fail-closed eligibility? | schema + adapter stubs; local llama.cpp/Ollama/OpenAI-compatible endpoints | schema + local-endpoint smoke gate | source-documented + locally-observed |
| `auth-planes` | Can route auth (native sign-in / BYOK / OAuth, no interception) stay separate from operator auth? | threat model + receipt fixtures | new auth-plane fixture | source-documented |
| `goal-command` | Does in-session `/goal` compile to one bounded GoalSpec/ArmRun with Stop-mode cancellation? | spec + inert replay of goal→spec→admit | M1A planning replay gates (existing) | locally-observed |
| `acp-suite` | Can one ACP client drive a suite of upstream agents as engines while Recursion keeps session/authority? | adapter design + fake ACP transport fixture | new `check.py` (fake transport) | source-documented |
| `consultation-chat` | Does bounded consultation + UI projections cover cross-session chat without an authority-bearing transcript? | envelope design + fixtures | new consultation fixture | source-documented |

hit ratio; OpenTelemetry-style spans. **Reject** a single scalar "Quality-Adjusted Efficiency" —
OR-017/OR-024 require the Pareto vector.
