## Retrieval limitations and freshness

- ECMA 2019/2024 single-page HTML exceeded the browser retrieval size; the official fixed 2024 PDF was read instead. The report does not silently replace RFC 8785's normative reference edition.
- Direct RFC Editor erratum opens failed while the official indexed result returned the complete record. Negative-zero status is reported with this limitation; M1B's independent rejection requirement was directly retrieved.
- Public latest pages sometimes showed prerelease or later-family labels. They are identified as moving documentation, not project pins or recommended upgrades. Versioned serde_json, Node, Jackson and Java anchors reduce this ambiguity where possible.
- No source archive digest was manufactured for public pages. Exact public-page archival hashes and candidate binary/package hashes remain future verification inputs, not observed evidence.
- Failed/unused URLs were not treated as supporting evidence: Go 1.24 package fetch, ECMA oversized HTML, failed Jackson Javadoc and failed GitHub CanonicalABI open were replaced with the retrieved primary sources above.
